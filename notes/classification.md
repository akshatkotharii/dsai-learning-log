# Classification: first map

## Where this fits

Classification is a supervised learning task. A model learns from examples with known labels and predicts a category for a new example.

Examples: predict whether an email is spam, or classify an image by its subject.

## Methods in this unit

- **Logistic regression:** estimates class probabilities. Despite its name, it is commonly used for classification.
- **Decision tree:** predicts by following feature-based questions. Trees can be used for classification or regression.
- **K-nearest neighbors (KNN):** predicts using labels of nearby training examples. KNN can also be used for regression.
