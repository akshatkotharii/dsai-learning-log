# Notes

Keep one file per concept or closely related group of concepts. Prefer a clear explanation and a small example over copied slides.

Suggested note shape:

1. What problem does this method solve?
2. Core idea, in my own words
3. How it works, step by step
4. Important math, assumptions, and terms
5. Small worked example
6. Strengths, limitations, and comparison to other methods
7. What still confuses me
8. Sources or course references
