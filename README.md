# DSAI Learning Log

Notes, Python exercises, and weekly reflections from my Data Science and AI coursework.

This repository records what I understand, what I tried, and what I want to revisit. It is a learning log, not a polished textbook.

## Current topics

- Supervised learning
- Classification: logistic regression, decision trees, k-nearest neighbors (KNN)

## Repository map

- `notes/` — concept notes written in my own words
- `weekly/` — short weekly study logs
- `python/` — Python exercises and small experiments

## How I update this

After studying, I add or improve a topic note. When I write code, I put it in `python/` and include a short comment or README explaining what I was trying to learn. At the end of the week, I add a brief log and use one takeaway for an X post.

## Git basics

Run these commands from this repository's folder:

```bash
git status
git add notes weekly python
git commit -m "Add notes on <topic>"
git push
```

For a new Python file, replace the folder names in `git add` with its path, for example `git add python/knn_demo.py`.

## Academic integrity

Write explanations in my own words. Follow course rules before publishing assignment questions, solutions, datasets, or restricted course material.
